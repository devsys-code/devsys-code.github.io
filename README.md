## 📋 Descripción

Portafolio web profesional de **Derlys Daniel Alvarado Mendoza (`devsys-code`)**, Full Stack Developer y Arquitecto de Software SaaS. Diseñado con una interfaz moderna, minimalista y de alto rendimiento que exhibe el ecosistema de proyectos SaaS Multitenant y la suite de habilidades de IA.

## 🚀 Características Principales

- ⚡ **React 19 + Vite**: Compilación ultra rápida con React Compiler habilitado.
- 🎨 **Tailwind CSS v4**: Estilos modernos con variables CSS nativas, temas claro/oscuro dinámicos y transiciones fluidas.
- 🌐 **Internacionalización (i18n)**: Soporte completo para Español e Inglés sin recargar la página.
- 📱 **Diseño 100% Responsivo**: Adaptado perfectamente a móviles, tablets y monitores de escritorio.
- 🔄 **Filtro de Proyectos con Iconos**: Filtrado interactivo por Backend, Frontend, Full Stack y Skills de IA con tooltips animados.
- 📬 **Canales de Contacto Directo**: Integración con WhatsApp directo, LinkedIn, Correo electrónico y GitHub.
- 🚀 **Despliegue Automatizado**: Pipeline CI/CD con GitHub Actions para despliegue continuo en GitHub Pages.

## 💻 Instalación y Desarrollo Local

```bash
# 1. Clonar el repositorio
git clone https://github.com/devsys-code/devsys-code.github.io.git

# 2. Entrar al directorio
cd devsys-code.github.io

# 3. Instalar dependencias
npm install

# 4. Iniciar servidor de desarrollo
npm run dev

# 5. Construir para producción
npm run build
```
